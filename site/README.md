# Relai site

Landing page for figma-relai — Vite + React + Tailwind, three languages (EN/JA/ZH), no runtime dependencies beyond React and lucide icons.

```
npm install
npm run dev       # local dev
npm run build     # dist/
```

Design notes: brand amber `#FFB000` on warm black; the pairing is IBM Plex Mono (machine voice: labels, ledger, commands) × IBM Plex Serif / Noto Serif JP·SC (human voice: display + body); the session ledger uses real numbers from a real session (July 2026) — keep it honest when editing. Panel screenshots live in `public/panel/` and mirror `assets/plugin-ui*.png` from the repo root.
